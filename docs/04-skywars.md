# 04 — SkyWars (правила игры + настройка)

Конкретная игра поверх каркаса. Вся логика — в `game/SkyWarsGame` (наследник
`Minigame`); ядро (арены/жизненный цикл/меню/снапшоты/откат/HUD/стата) об игре не
знает. Package root: `ru.kiviuly.skywars`.

## Концепция

Соло **last-man-standing** на парящих островах. Побеждает последний выживший.
«Кто больше нанесёт урона» — это **разминка в лобби**, не условие победы.

Ход сессии:

1. **Лобби.** Игроки ждут старта и **дерутся на разминке** («Избиение в лобби»):
   удары не наносят реального урона, но **считаются** — фейковый флэш/звук/отдача,
   чтобы бой ощущался. Перед десантом объявляют **топ-3 самых буйных**.
   Тут же игрок выбирает **кит** предметом-селектором (slot 0).
2. **Десант из капсул.** На старте каждого запирают в **стеклянную капсулу** над его
   островом (спавн арены = точка капсулы). Через `capsule-seconds` капсула исчезает →
   **медленное падение** + резист (грейс `grace-seconds`) → игрок приземляется на остров
   со своим китом.
3. **Матч.** Лутают **сундуки** (взвешенные категории), дерутся, строят мосты к
   чужим островам. Смерть (в т.ч. падение в пустоту) → **спектатор**, без респавна.
4. **Финиш.** Остался один — победа; вышло время (`match-duration-seconds`>0) — ничья.
   В HUD во время матча — «Лидер урона»; в итоге победителя — его убийства и урон.

## Настройки арены (числа игры)

Через `arena.getSetting/setSetting`, задаются в `/sw gui <ID>` → **Параметры**
(2-й ряд) или правкой `arenas/<id>.yml` секции `settings`:

| Ключ | Смысл | Дефолт |
|---|---|---|
| `capsule-seconds` | сколько держать в капсуле до раскрытия | 5 |
| `grace-seconds` | резист/иммунитет после десанта (сек) | 6 |

Плюс общие числа каркаса (мин/макс игроков, отсчёты, длительность) — там же.

## Цепочка настройки арены

```
/sw create <ID>              создать арену (мир = текущий, лобби = здесь)
/sw gui <ID>                 хаб настройки:
  → Точки → Лобби            лобби = твоя позиция (место ожидания/разминки)
  → Точки → Спавны           маркер: ПКМ по блоку в ВОЗДУХЕ над островом = точка капсулы
  → Точки → Сундуки          выбрать категорию → маркер сундука → ПКМ по блоку = сундук
  → Параметры                мин/макс игроков, отсчёты, capsule/grace
/sw check <ID>               валидатор (нужны лобби + спавны)
/sw enable <ID>              включить; игроки заходят /sw или /sw join <ID>
```

Важно: **точка спавна = позиция капсулы**, ставь её в воздухе над островом (игрок
падает вниз на остров). Точка-сундука = блок, который на старте станет сундуком —
ставь их с небольшим зазором.

## Киты (глобальные)

Общие для всех арен, файл `kits.yml`. Игрок выбирает в лобби (`none`/`random`/
конкретный; дефолт — `default-kit` в `kits.yml`). Броня надевается автоматически по
материалу.

Настройка: `/sw kits` → список → **ЛКМ** редактировать предметы (перетаскивай
предметы в креативе, закрой — сохранится), **ПКМ** сделать дефолтным, **Shift**
удалить, **Создать** — ввести id. Имя/иконку — кнопками в редакторе.

## Лут сундуков

**Категории — глобальные** (`loot.yml`), **точки-сундуки — пер-арена**
(`arenas/<id>.yml`, каждая точка несёт список id категорий). Сундук на старте
наполняется всеми своими категориями: каждая кладёт `min..max-per-chest` слотов
взвешенным выбором. `refill-seconds` > 0 — пополнять пустые слоты по закрытию
(0 = не пополнять, классика). Содержимое исчезает с откатом мира после матча.

Настройка: `/sw loot` → категории (создать/редактировать/удалить). В редакторе:
предметы перетаскиванием (**GUI пишет вес 1** — для кастомных весов правь `loot.yml`),
± кнопки min/max/refill, имя/иконка. Привязка к аренам — через
`/sw gui <ID>` → Точки → Сундуки.

## Где что в коде

- `game/SkyWarsGame` — все хуки: `onLobbyAttack` (разминка), `onStart`
  (`announceWarmup`+`placeChests`+`buildCapsules`), `onTick` (`releaseCapsulesIfDue`),
  `giveLoadout` (кит), `onEnd`/`scoreboardLines` (итоги/HUD), `onChestClosed` (рефилл).
- Состояние матча — только в `session.data()` (`warmup-damage`, `capsule-*`,
  `chest-cats`, `refill-pending`, `match-damage`, `kit-choice:<uuid>`), не в полях класса.
- Обобщённое расширение ядра — `Minigame.onLobbyAttack` + `Arena.chestSpots`; остальное
  SkyWars-специфичное — в `SkyWarsGame`/`SkyWarsListener`/новых меню/реестрах.
