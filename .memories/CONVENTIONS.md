# CONVENTIONS — стиль и инварианты

Last updated: 2026-07-24 (после миграции на платформу MgCore)

## Где что живёт

Этот репозиторий — **только игра**. Каркас — во внешнем `../kiviuly-mg-core`
(модули `mg-api` — контракты, `mg-core` — реализация-плагин). Правило простое:

- Правила SkyWars → `game/SkyWarsGame` + `listener/SkyWarsListener` + свои
  реестры/меню **здесь**.
- Всё, что годится любой игре → в `kiviuly-mg-core`, **обобщённо** (именованные
  группы точек `Arena.spots(group)`, числа через `Arena.getSetting/setSetting`,
  хуки `Minigame`). Игро-специфичного кода в ядре быть не должно: там уже живут и
  другие игры.
- Понадобилось расширить платформу — правится соседний репо, и это отдельная
  задача со своей сборкой; здесь только пользуемся контрактом `mg-api`.

## Стиль кода

- **Java 25**, Paper API. Никакого NMS/рефлексии — только публичный API.
- **Скобки Allman** (открывающая на своей строке). Короткие guard-ветки в одну
  строку: `if (x == null) {return;}`.
- **Импорты, а не FQN.** Группы: `java` → `net.kyori` → `org.bukkit` →
  `ru.kiviuly.mg` → `ru.kiviuly.skywars`. При коллизии имён импортируй тот, что
  чаще в файле; второй — полным именем.
- **Пакеты по подсистемам** (`game/`, `kit/`, `loot/`, `listener/`, `menu/`),
  без god-utils. Утилиты не заводим — берём `ru.kiviuly.mg.api.util.*`.
- **Комментарии/Javadoc — по-русски**, только там, где код сам не объясняет.

## Инварианты (не ломать)

1. **Тексты игрокам — ТОЛЬКО из `messages.yml`** (MiniMessage) через
   `ru.kiviuly.mg.api.util.Msg`. Свой каталог домешивается в ядровой вызовом
   `Msg.merge(this)` в `onEnable`; **ключи игры — в пространстве `skywars.*`**,
   чтобы не столкнуться с ключами ядра и других игр. Новый текст = новый ключ.
2. **Логи сервера — только ASCII** (Windows-консоль коверкает не-латиницу).
   Игрокам — MiniMessage; в консоль — ASCII (`DebugLog` фильтрует не-ASCII в `?`).
3. **Данные на предметах/сущностях — только PDC** (`mg.api.util.Keys`, метки
   спец-предметов — `Items.special`/`Items.isSpecial`). Парсить лор/имена запрещено.
4. **Любое изменение блока мира в матче** — сначала `match.rememberBlock(block)`,
   иначе cleanup не откатит. **Заспавненные сущности** — `match.trackEntity(...)`.
5. **Снапшот игрока неприкосновенен** — им управляет ядро (`PlayerSnapshot` в
   `mg-core`). Игра не трогает инвентарь вне своих хуков (`giveLoadout`,
   `onLobbyJoin`) и никогда не «восстанавливает» игрока сама.
6. **Игровая логика — main thread.** Async — только хранилище (`StatsService`).
   Никаких async-обращений к Bukkit API.
7. **GUI — только через `ru.kiviuly.mg.api.menu.Menu`** (InventoryHolder).
   Заголовки инвентарей не сравниваем.
8. **MiniMessage: плейсхолдеры не должны совпадать с именами тегов** — для чисел
   `<n>` (не `<gold>`). **Ключи YAML не должны быть голыми `on/off/yes/no`**
   (парсятся как boolean) — пиши `state-on`/`state-off`.

## Состояние — в матче, не в полях

`Minigame` — **одна инстанция на плагин** и без состояния матча: матчей может идти
несколько. Всё per-match — в `Match.data()` (ключи-константы, см. `WARMUP_KEY`,
`CAPSULE_BLOCKS_KEY`) и `MatchPlayer`. Поле в `SkyWarsGame` допустимо только для
неизменяемых зависимостей (`plugin`, `core`, константы).

## Команды

Своей команды у плагина нет. Админка — `/mg` (ядро, права `mg.admin`); игровые
подкоманды приходят в `SkyWarsGame.onCommand(p, sub, args)` — сейчас `kits`,
`loot`, `chests <arena>`. Новую подкоманду добавляй сразу в трёх местах:
`onCommand`, `tabComplete`, `helpLines` (+ ключ в `messages.yml`).

## Процесс

- Проверка изменений: собрать и положить на сервер **оба** плагина —
  `:mg-core:deploy` из `../kiviuly-mg-core` и `./gradlew deploy -PdeployDir=<server>/plugins`
  отсюда → перезапуск → лог без стектрейсов
  (`[SkyWars] SkyWars enabled, game registered: skywars`) + ручная проверка фичи.
- После нетривиального изменения — обнови `.memories/STATE.md` (см. `INDEX.md`,
  «Правило поддержки»). Память противоречит коду → прав код, чини память.
